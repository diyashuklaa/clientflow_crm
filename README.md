🌐 ClientFlow CRM

ClientFlow CRM is a modern, modular Customer Relationship Management system built with Flask.
It provides powerful features to manage customers, track follow-ups, analyze business performance, and generate data-driven insights with integrated Python data-science utilities.

🚀 Tech Stack
🛠️ Backend
Python (Flask Framework)
Flask Blueprints (Modular Architecture)
SQLAlchemy ORM
SQLite Database
Jinja2 Templates
🎨 Frontend
HTML5, CSS3
Bootstrap 5
JavaScript
Bootstrap Icons
📈 Data Science & Analytics
NumPy – numerical calculations
Pandas – data manipulation & cleaning
Scikit-learn (light usage) – forecasting & segmentation logic
Matplotlib (optional) – for internal visualization
Custom Python-based analytics logic
🧠 Custom Analytics Utilities
Customer Segmentation Engine
Customer Lifetime Value (CLV) Calculator
Conversion Rate Analyzer
Revenue & Follow-up Forecasting
Data Cleaning & Preprocessing Helpers

These utilities are custom-built modules using Python + data science logic to generate actionable insights inside the CRM.
